# trabajo-practico-integrador-2

Frontend en React + Vite + Tailwind CSS para el Sistema de Gestión de Blog Personal (TP Integrador N° I).

**Alumno:** Leandro Sanabria

## Backend utilizado

https://github.com/leandroexequielsanabria7/trabajo-practico-integrador-1

## Cómo levantar el proyecto

1. Levantar el backend del TP I (XAMPP con MySQL encendido y `npm run dev`) en `http://localhost:3000`.
2. En este proyecto ejecutar:

```bash
npm install
Copy-Item .env.example .env
npm run dev
```

3. Abrir `http://localhost:5173`.
